## Por que Markdown?

Markdown é uma linguagem de marcação leve que permite escrever conteúdo de forma simples e legível. Aqui estão algumas vantagens:

- Fácil de escrever e ler
- Converte automaticamente para HTML
- Suporta código, links e imagens
- Amplamente usado na comunidade de desenvolvedores
