
# O que é Infrastructure as Code e quais os benefícios de adotar ?


IaC é um novo meio de controlar, configurar e provisionar infraestrutura de computação em nuvem, como AWS, Azure, GCP e outros. Anteriormente esse provisionamento era feito de forma manual pelo time de Operations, então era algo como provisionar instâncias EC2 que rodariam o código desenvolvido pelo time de DEVS. Já é possível notar alguns pontos de melhoria nesse processo só com essa pequena descrição.
