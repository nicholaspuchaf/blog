# Configurando um Blog com SvelteKit

Neste post, vou mostrar como configurei este blog usando tecnologias modernas.

## Stack Tecnológica

Para este blog, escolhi as seguintes tecnologias:

- **SvelteKit**: Framework moderno e rápido
- **Bootstrap**: Para estilização via CDN
- **mdsvex**: Para processar arquivos Markdown
- **Cloudflare Pages**: Para hospedagem

## Vantagens do Markdown

Escrever posts em Markdown oferece várias vantagens:

1. **Simplicidade**: Sintaxe fácil de aprender
2. **Portabilidade**: Arquivos de texto puro
3. **Versionamento**: Fácil de versionar com Git
4. **Foco no conteúdo**: Menos distrações com formatação

## Como Funciona

O mdsvex processa arquivos `.md` e os transforma em componentes Svelte automaticamente. Isso significa que posso:

- Escrever conteúdo em Markdown
- Usar componentes Svelte quando necessário
- Ter sintaxe highlighting para código
- Adicionar metadados com frontmatter
